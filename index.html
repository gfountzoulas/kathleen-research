Kathleen

Machine memory you can read, prove, and erase.

A byte-level architecture whose knowledge lives in an addressable holographic memory, not in weights. Writing is one-shot. Recall is algebra. Deletion is subtraction — with a mathematical audit trail. Small enough to run where the data lives.

02

Four properties, by construction

Located
Every fact has an address. Knowledge in weight-based models can be neither located nor removed; here it is a vector you can point to.
Erasable
The right to be forgotten — GDPR Article 17 — as an algebraic operation, with a before/after audit any third party can run. Compliance by architecture, not by policy.
Attributable
Every answer traces back to the stored memory that produced it. No fabricated provenance.
Small
The entire stack runs on edge-class hardware. No cloud dependency, no third-party model, no tokenizer. The data never has to leave the device.

04

Method

Verdict criteria are fixed before each experiment runs. Negative results are reported as prominently as positive ones. Every failure receives an autopsy with discriminating control arms before any fix is attempted. The full lineage — five months, 2,300+ archived experiments with timestamped version history — is preserved.

Trustworthy cognition begins with a trustworthy research process.
